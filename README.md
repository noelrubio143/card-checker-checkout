# card-checker-checkout

A simple checkout-style card validation form built with HTML, CSS, and JavaScript.

## Features
- Card number formatting with spaces
- Card brand detection
- Luhn validation
- Expiry validation
- CVV validation
- Checkout UI mockup

## Run locally
Open `index.html` in a browser.

## Note
This is a local demo for validation logic only. It does not verify a real live card with a bank or payment provider.
